プライバシーポリシー

最終更新日: 2026年10月21日

本アプリは、ユーザーのプライバシー保護を最優先事項として設計されています。

第1条 収集する情報

ScoreVaultは、以下の情報を収集・利用します。

  • ゲームログ（タイトル・評価・レビュー・プレイ時間・画像URL等）
  • Google ログインで取得する情報（メールアドレス・氏名・プロフィール画像URL）
  • Sign in with Apple で取得する情報（氏名・メールアドレス）。メールアドレスを非公開にした場合は、Apple が発行する転送用のメールアドレス（@privaterelay.appleid.com）となります。アプリの画面には、Apple アカウントのメールアドレスを表示しません。
  • Firebase Authentication が発行するユーザー ID（UID）
  • Firebase Firestoreによるクラウド同期データ（サインインして同期機能を使用した場合のみ）
  • Steam / IGDB 連携情報（公開ゲーム情報・実績情報）
  • 広告識別子（iOS では IDFA、Android では AAID）— AdMob による広告配信のために使用します。iOS では、初回起動時に表示される App Tracking Transparency（ATT）の許可ダイアログで許可いただいた場合のみ、IDFA を広告配信に使用します。許可しない場合でも、アプリの機能は制限されません。許可の設定は、端末の「設定」アプリからいつでも変更できます。
  • 利用状況（画面遷移など）— Firebase Analytics により収集します。ユーザー ID とは紐づけていません。
  • クラッシュ情報・端末情報 — Firebase Crashlytics により収集します。

サインインは任意です。サインインしなくても、すべての記録機能をご利用いただけます。サインインすると、クラウド同期をご利用いただけます。サインイン方法は Google と Apple です。

第2条 利用目的

収集した情報は以下の目的にのみ利用します。

  • アプリ内でのゲームプレイ記録の表示・管理
  • 複数デバイス間でのデータ同期
  • ゲーム情報の自動補完（Steam / IGDB API 連携）
  • 広告の配信
  • 不具合の調査とアプリの改善

第3条 データ管理

  • 主データはローカルの Isar Database に保存されます。
  • クラウドへの保存は同期機能を有効にした場合のみ行われます。
  • 第三者への個人情報の提供・販売は一切行いません。

第4条 外部サービス

本アプリは以下の外部サービスを利用しています。各サービスのプライバシーポリシーも併せてご確認ください。

  • Firebase（Authentication・Firestore によるクラウド同期、Analytics、Crashlytics）— Google LLC 提供
  • Google ログイン — Google LLC 提供
  • Sign in with Apple — Apple Inc. 提供
  • Steam API（ゲーム情報取得）— Valve Corporation 提供
  • IGDB API（ゲーム情報取得）— Twitch Interactive, Inc. 提供
  • AdMob（広告配信）— Google LLC 提供

第5条 ユーザーの権利

  • アプリ内でアカウントを削除できます。アプリの「設定」画面の「ACCOUNT」にある「アカウントを削除」から行ってください。
  • 削除されるのは、アカウントと、クラウドに同期されたデータです。
  • 端末内のローカルデータは、アカウントを削除しても残ります。ローカルデータはアプリをアンインストールすることで消去されます。
  • 直近にログインしていない場合は、「再度ログインしてから削除してください」と表示されます。その場合は、再度ログインしてから削除してください。

第6条 ポリシーの変更

法令の変更やアプリのアップデートに伴い、本ポリシーを随時改定することがあります。重要な変更についてはアプリ内またはこのページにて通知するよう努めます。改定後のポリシーは本ページに掲載した時点から効力を発します。
