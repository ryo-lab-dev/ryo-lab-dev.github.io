GCP ACE（Associate Cloud Engineer）の勉強法

公式の試験ガイドを軸に、練習問題で苦手をつぶす（2026年10月26日）

Google Cloud の資格「Associate Cloud Engineer（ACE）」は、Compute Engine・IAM・VPC・Cloud Storage など、幅広いサービスの知識が問われます。範囲が広いぶん、「どこから手を付けるか」「どこが苦手か」が見えないまま進めると、時間がかかりがちです。

このページでは、ACE の勉強を 4 つの手順に分けて紹介します。各手順で、学習アプリ CloudKata での進め方も書いています。

1. 公式の試験ガイドで、範囲をつかむ

最初に、Google Cloud が公開している ACE の試験ガイドで、出題の分野と比重を確かめます。試験の形式・時間・料金などは変わることがあるため、受験前には必ず公式の情報を確認してください。

範囲を眺めたら、「仕事で触ったことがある」「名前だけ知っている」「まったく知らない」に分けておくと、次の手順で優先順位を付けやすくなります。

2. カテゴリ別の練習問題で、苦手を見つける

範囲をつかんだら、カテゴリごとに練習問題を解いて、自分の苦手を数字で確かめます。最初から高得点を狙う必要はありません。どのカテゴリで間違えるかが分かれば十分です。

CloudKata では: Compute Engine・IAM・VPC・Cloud Storage など、主要なカテゴリの 4 択問題を、出題数・カテゴリ・難易度を選んで解けます。カテゴリ別の正答率はレーダーチャートで確認できます。収録している問題はすべて独自に作成した練習問題で、実際の試験問題とは関係ありません。

3. 間違えた問題は、解説とコンソールで確かめる

ACE は「どのサービスを、どう設定するか」を問う問題が中心です。間違えた問題は、答えを覚えるだけでなく、公式ドキュメントで仕組みを読み、無料枠の範囲でコンソールを実際に操作してみると定着します。

CloudKata では: 各問題の解説に、コンソールでの操作手順と公式ドキュメントへのリンクが付いています。

4. 苦手だけを繰り返し、毎日少しずつ続ける

全範囲を何周もするより、正答率の低い問題だけを繰り返すほうが効率的です。1 日 10 分でも、毎日続けるほうが記憶に残ります。

CloudKata では: 正答率の低い問題を自動で集めて解き直す「苦手克服モード」があります。連続学習日数（ストリーク）・バッジ・デイリーチャレンジで、続ける習慣づくりも後押しします。一度読み込んだ問題は、オフラインでも解けます。

CloudKata について

CloudKata（クラウドカタ）は、Google Cloud の資格 Associate Cloud Engineer の学習を支える、4 択形式の問題集アプリです。サインインなしでも 30 問まで無料で試せます（広告あり）。

  • カテゴリ・難易度を選べる問題演習
  • 正答率の低い問題を集める苦手克服モード
  • カテゴリ別正答率のレーダーチャートと学習の推移
  • 解説にコンソールの操作手順と公式ドキュメントへのリンク
  • オフラインでの演習
