Google Cloud IAM の勉強方法

ACE で問われる考え方を 3 つに絞る（2026年11月20日）

Google Cloud の資格「Associate Cloud Engineer（ACE）」では、IAM（Identity and Access Management）の問題がよく出ます。ロールの名前が多く、「どのロールを付ければよいか」で迷いやすい分野です。

ただ、名前を 1 つずつ暗記しようとすると続きません。このページでは、IAM を 3 つの考え方に絞って整理します。後半では、学習アプリ CloudKata での進め方も書いています。ロールの一覧や仕様は更新されるため、細かい点は公式ドキュメントで確認してください。

1. 「誰が・何を・どこに」で考える

IAM の設定は、「誰に（プリンシパル）」「どのロールを」「どのリソースに」付けるか、の組み合わせです。問題文を読んだら、まずこの 3 つを書き出します。

  • 誰が: ユーザー、グループ、サービスアカウントなど
  • 何を: 付けるロール（権限のまとまり）
  • どこに: 組織・フォルダ・プロジェクト・個別のリソース

権限は、上の階層（組織・フォルダ・プロジェクト）で付けると、その下のリソースにも引き継がれます。「どの階層で付けるか」は、範囲の広さを決める大事な判断です。

2. ロールの種類を区別する

ロールは大きく 3 種類に分けられます。

  • 基本ロール: オーナー・編集者・閲覧者。範囲が広く、本番での常用はすすめられません
  • 事前定義ロール: サービスごとに Google が用意した、用途別のロール
  • カスタムロール: 必要な権限だけを自分で組み合わせたロール

問題では、「基本ロールでは広すぎる。事前定義ロールで足りないときに、カスタムロールを作る」という順番で考えると、選択肢を絞りやすくなります。

3. 迷ったら「最小権限」で選ぶ

最小権限の原則とは、作業に必要な権限だけを付けることです。選択肢が複数あるときは、次の順で考えます。

  • 作業に必要な操作だけを含むロールか（広すぎないか）
  • 個人ではなく、グループやサービスアカウントに付けているか
  • アプリが使う権限を、人のアカウントではなくサービスアカウントに付けているか

「全員にオーナーを付ける」のような選択肢は、ほぼ誤りと考えて構いません。

4. 練習問題で、考え方を定着させる

考え方を頭に入れたら、問題を解いて確かめます。間違えたときは、答えを覚えるのではなく、上の 3 つのどこでずれたかを確かめると、次の問題にも使えます。

CloudKata では: カテゴリに「IAM & Security」があり、このカテゴリだけを選んで、難易度を指定して解けます。各問題の解説に、公式ドキュメントへのリンクが付いています。正答率の低い問題は、苦手克服モードでまとめて解き直せます。収録している問題はすべて独自に作成した練習問題で、実際の試験問題とは関係ありません。

CloudKata について

CloudKata（クラウドカタ）は、Google Cloud の資格 Associate Cloud Engineer の学習を支える、4 択形式の問題集アプリです。サインインなしでも 30 問まで無料で試せます（広告あり）。

  • カテゴリ・難易度を選べる問題演習
  • 正答率の低い問題を集める苦手克服モード
  • カテゴリ別正答率のレーダーチャートと学習の推移
  • 解説にコンソールの操作手順と公式ドキュメントへのリンク
  • オフラインでの演習
