Features

サイズ管理を、もっとシンプルに。

服選びの迷いをなくす。試着室での確認をなくす。あなたのサイズを、いつでも正確に。

01
シルエットUIで全身を記録

人体シルエットを見ながら、身長・体重・首周り・胸囲・ウエスト・肩幅・袖丈・靴サイズなど標準21部位を記録。左右10種の指輪サイズ（号）にも対応。ホームでは「5 / 11 項目完了」のように登録状況が一目でわかります。

02
変化を記録・追跡

cm / mm / kg / g / 号 / inch の単位切り替えとメモに対応。前回値付近の「よく使う値」ワンタップ入力で更新もスムーズ。部位ごとの更新履歴（直近3件）で、体の変化をいつでも振り返れます。

03
完全オフライン＆ロック

クラウド不要。体型・計測データは端末内のみに保存し、外部へは送信しません。4桁パスコードに加え、生体認証（Face ID / 指紋）でのロック解除も設定で選べます（任意）。「全データ削除」も設定から。

04
なんでも項目にできる

視力・血圧・平熱・コンタクト度数・タイヤサイズなど、標準にない情報も項目名・値・単位・メモで追加。各セクションの「＋」から追加・削除・並び替えができます。

05
家族分のプロフィール

名前・誕生日・血液型・アレルギーを登録でき、年齢や「次の誕生日まであと◯日」も表示。複数人を登録してタップで切り替え、ドラッグで並び替えもできます。

06
完全無料・広告のみ

1人目のプロフィールはそのまま使えます。2人目以降は動画広告を1回視聴すると追加でき（上限なし）、課金はありません。

Privacy First
