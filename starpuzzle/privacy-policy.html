プライバシーポリシー

最終更新日: 2026年10月31日

Ryo-Lab チーム（以下「運営者」）は、ロジックパズルアプリ「StarPuzzle」（以下「本アプリ」）における、利用者の情報の取り扱いについて、以下のとおり定めます。

第1条 取得する情報

本アプリは、アカウント登録やログインを必要としません。氏名・メールアドレス・位置情報・連絡先などの個人情報は取得しません（広告配信のための IP アドレス・広告 ID などを除きます）。機能の提供に必要な範囲で、次の情報を取り扱います。

端末の中にだけ保存する情報（外部へ送信しません）

情報内容・目的
遊んだ記録問題ごとのクリアの有無・クリアまでのタイム・使ったヒントの数。連続日数の表示のため
途中の盤面各マスの状態（空・×・★）、経過時間、操作の履歴。途中で閉じても続きから再開するため
1 日の無料枠その日（日本時間）の日付・使った数・広告で追加した数
設定「★を置いたら自動で ×」・振動のオン・オフ
広告の表示頻度前回の全画面広告を表示した時刻、その日のクリア回数。広告を出しすぎないため

自動的に取得される情報

  • 利用状況: 問題を始めた・クリアした・ヒントを使った・結果を共有した・問題一覧を開いた・広告で無料枠を追加した、といった操作の種類と、盤面のサイズ・クリアまでの秒数・ヒントの数。個人を特定する情報は含みません（Firebase Analytics）。端末・OS・おおよその地域などの一般的な情報も、SDK が自動で取得します。
  • クラッシュ情報: アプリが異常終了したときの端末・OS の情報とエラーの内容（Firebase Crashlytics）。
  • 広告に関する情報: 広告の配信のため、端末の広告 ID・IP アドレス・端末情報・広告の表示と操作の情報などが広告事業者に送信されます（Google AdMob）。iOS では、広告 ID（IDFA）を使うために、起動時にトラッキングの許可（App Tracking Transparency）をお願いする場合があります。許可しなくても、本アプリのすべての機能を使えます（許可しない場合は、広告 ID は使われず、広告の関連性が下がることがあります）。許可の設定は、端末の「設定」から、いつでも変えられます。

第2条 利用目的

  • 本アプリの機能の提供・維持・改善
  • 不具合の調査、安全性の確保
  • 利用状況の把握と、機能・問題の改善
  • 広告の表示（本アプリの運営費用に充てるため）

第3条 外部サービスへの送信（委託・第三者提供）

本アプリは、次の外部サービスを利用しており、必要な情報がこれらの事業者に送信・保存されます。

サービス提供者送信・保存される情報目的
Firebase AnalyticsGoogle LLC利用状況（操作の種類、盤面のサイズ・秒数・ヒントの数）改善
Firebase CrashlyticsGoogle LLCクラッシュ情報（端末・OS の情報、エラーの内容）不具合の調査
Google AdMobGoogle LLC広告 ID・IP アドレス・端末情報・広告の表示と操作の情報 など広告の配信
Google の同意の確認（UMP）Google LLC同意の状態広告の同意の管理
  • 収集しない情報: 氏名・メールアドレス・住所・電話番号・ユーザー ID・位置情報（広告配信のための IP アドレスを除く）・連絡先・写真・健康情報・決済情報。
  • 法令に基づく場合を除き、上記以外の第三者に、利用者の情報を提供しません。
  • 新しい致命的なクラッシュが起きたときは、運営者の不具合管理のため、Crashlytics が検知したクラッシュのタイトル・発生箇所・アプリのバージョンだけが、運営者の GitHub の Issue として記録されます（利用者のデータは含みません）。
  • 「結果を共有」は、利用者が操作したときだけ、タイム・ヒントの数・連続日数を文字にして、端末の共有機能（ほかのアプリ）へ渡すものです。運営者のサーバーには送信されません。
  • 広告の配信にあたり、必要に応じて同意の確認画面（Google の User Messaging Platform）が表示されることがあります。表示された場合は、アプリの「設定」の「プライバシーの設定」から、あとで変更できます。
  • 上記の事業者（Google LLC）は米国の事業者で、利用者の情報は、米国など日本国外のサーバーで保存・処理される場合があります。米国の個人情報の保護に関する制度は、個人情報保護委員会の「外国制度（アメリカ合衆国）」で確認できます。各事業者は、それぞれのプライバシーポリシーやデータの取り扱いに関する規約に基づいて、情報を安全に管理するための措置を講じています。
  • 各サービスのプライバシーポリシー: Google プライバシーポリシー、Firebase のプライバシーに関する情報

第4条 保存期間と削除

本アプリにはアカウントがなく、運営者は、個人を特定できるデータを保有していません。

  • 端末の中の記録は、アプリを削除するまで端末に残ります。アプリを削除すると、記録もすべて削除され、元に戻せません。運営者のサーバーには記録がないため、運営者が復元・削除することはできません。
  • Firebase Analytics・Crashlytics・AdMob が取得した情報の取り扱いは、各事業者のプライバシーポリシーに従います。

第5条 広告について

本アプリには広告が表示されます（画面下のバナー、クリア後の全画面広告、ヒントや無料枠の追加のための動画広告）。広告の配信に使われる情報や、広告のパーソナライズの設定は、Android は端末の設定（Google 設定 → 広告）、iOS は端末の設定（プライバシーとセキュリティ → トラッキング、Apple 広告）から変更できます。

第6条 子どもの情報について

本アプリは子ども向けではなく、13 歳以上の方を対象としています。13 歳未満の方の個人情報を、意図して取得することはありません。

第7条 本ポリシーの変更

内容を変更する場合は、本アプリまたは本ページでお知らせします。重要な変更があるときは、わかりやすい方法でお知らせします。
